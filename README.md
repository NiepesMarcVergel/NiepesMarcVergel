## 🚀 Tier 1: Flagship Applications

### 🌾 [BukidLink](https://github.com/NoelSaludo/BukidLink.git)
*A cross-platform agricultural marketplace connecting farmers directly with consumers and facilitating modern trade.*

*   **The Challenge:** Agricultural supply chains rely heavily on middlemen, limiting direct farmer-to-consumer sales and lacking digital platforms tailored to farming communities.
*   **The Solution:** I developed a mobile application serving as an e-commerce storefront and specialized trading hub, providing farmers with inventory management tools and buyers with a bartering experience.
*   **Key Features:** Dual-Role Architecture for distinct user flows, an Interactive Trading System for custom bartering, and Real-time Communication integrated with Google's Gemini AI.
*   **Tech Stack:** Flutter, Dart, Firebase, Gemini AI, Cloudinary.

### 📍 [LocateIT](https://github.com/NiepesMarcVergel/LocateIT_2.git)
*A community-driven web application that allows users to share, discuss, and rank content through an integrated upvoting system.*

*   **The Challenge:** Communities need a focused platform to share insights while letting the best content naturally rise to the top through user engagement.
*   **The Solution:** I built a full-stack, MVC-based web application allowing authenticated users to create posts, leave comments, and upvote submissions using a relational database.
*   **Key Features:** Community Engagement Mechanics utilizing Post, Comment, and Upvote models, Secure Authentication, and an Optimized Frontend Pipeline.
*   **Tech Stack:** PHP, Laravel, Tailwind CSS, Blade, Vite.

## 🏢 Tier 2: Enterprise & Backend Systems

### ❤️ [Compassion in Action](https://github.com/NiepesMarcVergel/Compassion-In-Action-ft.-DBMS.git)
*A Java-based management system designed to coordinate charitable donations and streamline volunteer applications.*

*   **The Challenge:** Organizations need a centralized, reliable way to track donor contributions and match volunteers without relying on scattered spreadsheets.
*   **The Solution:** I built an application serving as a hub for charitable activities, providing tools for users to register and apply, complete with an administrative backend for application processing.
*   **Key Features:** Relational Database Architecture connecting dynamic notifications, Role-Based Workflows separating general users from administrators, and an Integrated Notification System.
*   **Tech Stack:** Java, MySQL, JDBC.
